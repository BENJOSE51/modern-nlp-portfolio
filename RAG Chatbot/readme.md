# 🧠 Production-Grade RAG Chatbot with Hallucination Detection & MLOps

A **production-ready Retrieval-Augmented Generation (RAG) system** built with **FastAPI, FAISS, and transformer models**, enhanced with **hallucination detection, evaluation metrics, CI/CD, MLflow tracking, and Dockerized deployment**.

This project demonstrates **end-to-end AI system design**, focusing not only on generation quality but also on **reliability, evaluation, and safe deployment**.

---

## 🚀 Key Features

- 🔍 Retrieval-Augmented Generation (RAG) using dense embeddings + FAISS
- 🧠 Hallucination Detection Layer to measure answer grounding
- 📊 Evaluation Metrics: coverage score, unsupported claim ratio, hallucination risk score
- ⚙️ FastAPI-based API for real-time querying
- 🧪 Automated Testing & CI Guardrails
- 📈 MLflow Integration for experiment & metric tracking
- 🐳 Dockerized Deployment
- 🔄 CI/CD Pipeline for safe iteration
